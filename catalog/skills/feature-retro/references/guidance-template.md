# Project guidance — accrued lessons

> Written by `feature-retro`, read by every skopos session working in this
> repo. Lessons are triggers, not opinions: each one names a moment a future
> session can recognise, and the concrete thing to do at that moment.
>
> Curated, not appended. Refine and increment `Seen:` rather than duplicating;
> delete what newer experience contradicts; keep this under ~40 lessons so it
> keeps getting read.

## How to use this file

- **Starting work here?** Skim the triggers. Read the bodies of any that match.
- **Adding a lesson?** It must pass three tests: it names a recognisable
  trigger, it prescribes a concrete action, and it would have changed what we
  did on the feature that produced it.
- **A lesson at `Seen: 3×`** has outgrown this file — promote it into the
  interview probe bank, the evaluation negative-scenario list, or a standing
  instruction.
